# Traceability matrix

One row per requirement: what must hold, where Cursor defines it (module of the Cursor Desktop 3.25.6 agent bundle, see [cursor-extraction.md](cursor-extraction.md)), where a Desktop capture shows it, the Pi API from [pi-map.md](pi-map.md), and the evidence that will prove it. Rows R1-R9 are the discrepancies found against the OMP remaster ([PLAN.md](../research/history/omp-remaster/PLAN.md)); they apply to Cursor Pi as requirements. S-rows cover the rest of the agreed scope ([project.md](project.md)).

Module paths are the bundle's marker paths without `../` and `dist/`; all of them occur in the extraction record [cursor-desktop-3.25.6.json](../research/extraction/cursor-desktop-3.25.6.json). Evidence methods, defined in PLAN.md "Traceability and evidence": **E1** formatter equality (Cursor's function and ours on the same inputs, byte compare); **E2** paired requests (same task in Cursor Desktop and Cursor Pi, request bodies compared); **E3** transcript replay; **E4** drift check (`bun tools/extract-cursor.mjs --check`). Nothing is built yet, so every evidence cell is planned.
