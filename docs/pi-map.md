# Pi map

For every in-scope Cursor mechanism ([project.md](project.md), "Scope"), the public Pi API that reproduces it, read from the pinned source: Pi `v1.3.0`, commit `71023aec1546d6d677a65669c5665c0927ce0dd0` ([pi-pin.json](../pi-pin.json)). Every link opens that commit at the cited line, and `bun tools/check-pi-refs.mjs` checks that each cited line exists and contains the backticked name in its link text. Where no public API covers a mechanism, the row names the blocker.

The extension API is declared in `packages/coding-agent/src/core/extensions/types.ts`; its guide is `packages/coding-agent/docs/extensions.md`. The clone is a set of extensions loaded into stock Pi with its own launch flags, not a fork ([decisions.md](decisions.md), D14).
