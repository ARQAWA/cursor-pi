### Шаг 1
Что: rg по всему репозиторию без папки `.git` (glob `!**/.git/**`), регистронезависимо, шаблон `(?i)(port|listen|http|api)`, режим строк, до 200 строк.
Зачем: вопрос открытый, места порта неизвестны, и слова вопроса («порт», «HTTP API») совпадают с шаблоном. Сводка рассуждения: «Inspecting repository for port configuration» (26 токенов рассуждения). Из 8 инструментов выбран rg, так как системный промпт велит для поиска текста использовать rg и Glob, а не shell.
Принцип: сначала широкий поиск по ключевым словам, чтобы увидеть всех кандидатов.
Результат: 6 993 совпадения, в ответ попали 191 строка. Выдача ушла в `inventory_seller/steam.rs` и `Cargo.lock` и не дошла до `rust/services/api`. Полезно: `config.toml:2` `service_url …:27099`, `config.toml:19` `port = 6432` (Postgres), `config.toml:84` `[api]`. Вход следующего запроса вырос на 4 348 токенов. Заголовок `[api]` стал причиной следующего шага.
### Шаг 2
Что: ReadFile `config.toml`, со строки 75, 35 строк.
Зачем: в шаге 1 найден заголовок `config.toml:84 [api]`, и агент проверил, есть ли в этой секции порт. Сводка рассуждения пуста (0 токенов), ответ модели 1,8 с.
Принцип: найденное место открывают и читают целиком, прежде чем делать вывод по одной строке.
Результат: файл 86 строк. Секция `[api]` содержит только `security_token`, значение скрыто, порта нет. Значит, порт задан не в конфиге. Вход вырос на 165 токенов. Позже проверено: Python-настройка берёт из `[api]` только токен, порт в ней константа (`settings/api.py:8,11`).
### Шаг 3
Что: rg по шаблону `api|API|bind|0\.0\.0\.0|127\.0\.0\.1|8080|27099`, только файлы `*.{rs,toml,yml,yaml,json,service,sh}`, до 300 строк.
Зачем: порта в конфиге нет (шаг 2), значит, он задан в коде. Агент искал места, где открывается сокет (`bind`, `0.0.0.0`), и API-имена. Число `27099` взято из `config.toml:2`, а `8080` в предыдущих результатах не встречалось, это «вывод:» из общих знаний модели. Сводка рассуждения: «Searching for default port configuration» (19 токенов).
Принцип: если ключ в конфиге не найден, ищи механизм, который открывает порт, а не слово «порт».
Результат: 193 совпадения, показано 179. Ключевые строки: `rust/services/api/src/main.rs:28` `const BIND = "0.0.0.0:55789"` и `:172` `TcpListener::bind(BIND).context("bind API listener")`. Также `docker-compose.app.yml:175` `command ["/app/api"]`, `:192` `host_ip 0.0.0.0`, и `redeploy_screen.sh:36`, где упомянуты и `/app/api`, и `python -u aApi.py`. Вход вырос на 4 747 токенов. Из-за фильтра без `.py` файлы `aApi.py` и `botApi.py` в поиск не попали. Это «вывод:» модели, которая искала в Rust-сервисе.
### Шаг 4
Что: финальный ответ без вызова инструментов (91 токен, ответ модели 2,8 с, вход 18 413, из кэша 13 056).
Зачем: в результатах шага 3 есть значение (main.rs:28) и строка его использования (main.rs:172). Этого достаточно для короткого ответа, сам `main.rs` агент не открывал. Вызовов больше не было, поэтому прогон завершился.
Принцип: отвечай, когда есть и значение, и место его использования.
Результат: «порт 55789 на 0.0.0.0, константа `BIND` в `rust/services/api/src/main.rs:28`, привязка там же, в :172». Строки проверены по файлу и совпадают.
