# Промпты

Дословные тексты из журнала адаптера. Имя файла: тип-хеш. Тип: system — системный промпт; context — служебный блок первого user-сообщения; subagent-task — system_reminder роли и бриф субагента; user-query — запрос пользователя; notification — уведомление о фоновом субагенте; dyn-* — ответы GetDynamicTools и CallDynamicTool; tools/ — наборы инструментов в формате запроса. Места появления и выводы — в [coverage/prompts.md](../coverage/prompts.md).
