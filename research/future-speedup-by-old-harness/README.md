## Evidence limits

Owner statements and observed agent actions support workflow preferences and failure mechanisms. Prompt-performance improvements remain hypotheses: no candidate A/B run or measured speedup was established. Earlier task-specific permissions, model choices, monitoring windows and review intensity must not be promoted to standing Cursor Pi rules. Later owner corrections supersede earlier choices; cancelled choices remain inactive.
